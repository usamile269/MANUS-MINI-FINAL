The bounded non-transactional GET audit identified multiple unreliable or dead providers. The following integrations returned DNS failures, 4xx/5xx responses, or timeout behavior and should not be primary paths: `google-search.bjcoderx.workers.dev`, `gemini-1-5-flash.bjcoderx.workers.dev`, `r-bots-free-apis.co08.art`, `api.alyachan.pro`, `okatsu-rolezapiiz.vercel.app`, `jawad-tech.vercel.app/download/ytdl`, `adeel-xtech-apis.vercel.app/api/ytmp4`, `api.vreden.my.id`, `wasifali.biz.id` without the required query, `eliteprotech-apis.zone.id/ytdown`, `api.nexoracle.com`, and TikWM feed search.

The following public endpoints answered successfully in the audit and may remain as bounded fallbacks where their command-specific schemas are confirmed: `api.cobalt.tools`, `api.microlink.io`, `catfact.ninja`, `dog.ceo`, `api.adviceslip.com`, `api.mymemory.translated.net`, and `api-fix.onrender.com/api/maker/attp`. A bare HTTP 200 does not prove a command endpoint is functional; command-specific probes are still required.

The audit intentionally skipped login, OTP, messaging, upload, and credentialed endpoints to avoid side effects. TikTok’s official Display API requires OAuth user access tokens; the bot therefore uses the public profile page parser for no-variable operation. SIM owner/CNIC/address data remains dependent on an external provider and cannot be made self-contained without an authoritative dataset; the parser currently handles nested and malformed JSON.

The full plugin-health check before the audit loaded all 74 plugins successfully. The combined syntax sweep was terminated because the long process exceeded its bound; later command-specific checks should be run separately and bounded.
